# 鲸鱼娘素材接入说明

放图进来即可，无需改代码（宿主路由 `/whale/assets/*` 自动服务，客户端自动加载，
图片缺失时回退为内置 SVG 表情）。

## 文件名约定（放到本目录）

| 文件 | 用途 |
| --- | --- |
| `whale-happy.png` / `.svg` | 呆萌表情（默认） |
| `whale-angry.png` / `.svg` | 生气（致命操作） |
| `whale-sleepy.png` / `.svg` | 困困（深夜高活跃） |
| `whale-dazed.png` / `.svg` | 无语（重试风暴） |
| `whale-hero.png` / `.svg` | DeepTrace 页面形象（品牌区/报告头） |

## 规格建议

- **SVG 优先**（透明背景、任意尺寸不糊）；PNG 用 512×512 及以上，透明背景
- 风格：轻二次元 + DeepSeek 蓝白（主色 #4D6BFE），与现有 UI 融合
- 表情差异要明显（眼睛/嘴），挂件尺寸约 40-48px 显示
- hero 形象建议横版或方形 1:1，约 120-160px 显示

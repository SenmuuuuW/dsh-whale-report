# 鲸鱼娘素材规格书

> 图片放进本目录后无需改代码：宿主 `/whale/assets/*` 自动服务，客户端自动加载；
> 图片缺失时自动回退内置 SVG 表情。提交 git 后随包发布。

## 📋 一共 5 张（4 张表情头像 + 1 张页面形象）

| 文件（必须用这个名字） | 用途 | 出现场景 |
| --- | --- | --- |
| `whale-happy.png` 或 `.svg` | 呆萌表情（默认） | 本期鲸评卡、分区小图标 |
| `whale-angry.png` 或 `.svg` | 生气表情 | 出现致命级操作时 |
| `whale-sleepy.png` 或 `.svg` | 困困表情 | 凌晨活跃 ≥25% 时 |
| `whale-dazed.png` 或 `.svg` | 无语表情 | 重试风暴 ≥5 次时 |
| `whale-hero.png` 或 `.svg` | DeepTrace 页面形象 | 概览页品牌区、报告头 |

## 📐 每张图的详细要求

### 表情头像 ×4（whale-happy / angry / sleepy / dazed）

| 项 | 要求 |
| --- | --- |
| 格式 | **SVG 优先**（透明背景、任意尺寸不糊）；PNG 必须 **512×512 及以上、透明背景** |
| 构图 | 头部占画面 **70-80%**，居中；不要画全身/半身（挂件用） |
| 画风 | 轻二次元 + DeepSeek 蓝白：主色 **#4D6BFE**，肚皮/腮红浅色（#DBE4FF / #FFB4C8） |
| 眼睛 | 居中偏上，**四种表情眼睛差异必须一眼可辨**（见下表） |
| 嘴巴 | 与眼睛配套（见下表） |
| 阴影/描边 | 可带极浅描边，禁用深色粗描边、禁用渐变、禁用发光 |
| 显示尺寸 | 实际显示 40-48px（挂件）/ 16px（分区图标），所以细节要在大图下清晰，缩小后不糊 |

**四种表情的差异模板（照这个画）**：

| 表情 | 眼睛 | 嘴巴 | 附加 |
| --- | --- | --- | --- |
| `happy` 呆萌 | 大圆眼（黑瞳，亮光点） | 微笑弧线（开口笑更好） | 腮红、可带小尾巴翘起 |
| `angry` 生气 | 眉毛倒竖（> < 型）或眯眼 | 下撇扁嘴（或撇嘴） | 可加脸颊气鼓鼓的鼓起 |
| `sleepy` 困困 | 半闭线眼（一条弧线） | 小圆 O 嘴（打哈欠） | 可加一个 "z z" 气泡 |
| `dazed` 无语 | 豆豆眼（两个小黑点） | 平嘴（直线或小波浪） | 可加一滴汗珠 / 头顶黑线 |

### 页面形象 ×1（whale-hero）

| 项 | 要求 |
| --- | --- |
| 格式 | SVG 或 PNG（PNG 建议 **1024×1024**、透明背景） |
| 构图 | 1:1 方形或横版；可以画 **半身/全身** 的鲸鱼娘，比头像更完整 |
| 画风 | 同上：轻二次元 + 蓝白主色；可以带小道具（终端/气泡/代码符号）体现"Agent 数据"主题 |
| 显示尺寸 | 实际显示 120-160px，缩小后细节不糊 |
| 可选项 | 可以只做一张"站姿鲸鱼娘"，与四张表情头像风格统一 |

## ✅ 验收标准

- 4 张表情一眼能分清喜怒哀困
- 在 40px 小尺寸下依然清晰（眼睛、嘴巴可辨）
- 与现有 UI（白底、DS 蓝、细边框）融合，不突兀
- 文件名完全一致（大小写敏感）
